# Reference vehicle models

One directory per reference vehicle, each with its xacro URDF, the SDF generated at build time,
meshes under a licence file, and a `robot.yaml` manifest: `ugv_ref/` (P1-T01), `uav_quad_ref/` and
`uav_vtol_ref/` (P4-T03), `usv_ref/` (P5-T02). The directory is on `GZ_SIM_RESOURCE_PATH` once the
package is sourced.
